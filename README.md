## 🇮🇷 فارسی

### معرفی

**زیسترو (ZISTRO)** یک اپلیکیشن اندروید برای برنامه‌ریزی و پیگیری فعالیت‌های روزانه است که کاملاً **فارسی و راست‌به‌چپ** طراحی شده و از **تقویم شمسی (جلالی)** استفاده می‌کند. فعالیت‌هایت را با ساعت و روزهای تکرار تعریف می‌کنی، هر روز انجامشان را تیک می‌زنی، و اپلیکیشن به‌صورت خودکار به هر روز **امتیاز و وضعیت رنگی** می‌دهد. در پایان هم گزارش هفتگی، ماهانه و سالانه از پیشرفتت می‌بینی.

تمام داده‌ها **فقط روی گوشی خودت** ذخیره می‌شوند و برنامه برای کار کردن نیازی به اینترنت یا ثبت‌نام ندارد.

### ✨ امکانات

#### 📅 صفحه امروز
- نمایش **تاریخ شمسی زنده** به‌همراه نام روز هفته
- لیست فعالیت‌های امروز با **تیک انجام** (با یک لمس)
- کارت وضعیت و امتیاز امروز
- **تقویم شمسی** با قابلیت جابه‌جایی بین ماه‌ها؛ روزهای گذشته رنگ وضعیت می‌گیرند
- **اهداف سالانه**: افزودن هدف، تیک زدن پس از انجام و حذف
- **برنامه هفتگی**: تعداد فعالیت‌های هر روز هفته در یک نگاه (شنبه تا جمعه)
- دکمه **«روز اضطراری»** برای روزهایی که نتوانستی برنامه را انجام بدهی

#### 🎯 سیستم امتیازدهی و رنگ‌ها

| رنگ | وضعیت | امتیاز |
|:---:|:---|:---:|
| 🟢 سبز | همه فعالیت‌های آن روز انجام شده | ۱۰ |
| 🟡 زرد | روز اضطراری (به‌صورت دستی ثبت می‌شود) | ۵ |
| 🔴 قرمز | روز گذشته‌ای که فعالیت‌ها کامل انجام نشده | ۰ |
| ⚪ خاکستری | روز جاری، در حال انجام | — |

#### ➕ افزودن و ویرایش فعالیت
- عنوان فعالیت با **پیش‌نمایش درست متن فارسی** هنگام تایپ
- ورود ساعت با **قالب‌بندی خودکار ۲۴ ساعته** (مثلاً `21:30`) و اعتبارسنجی
- انتخاب **روزهای تکرار** هفتگی (یک یا چند روز)
- فعالیت‌ها فقط از روز ساخته‌شدنشان به بعد در گزارش‌ها حساب می‌شوند، پس گزارش‌های گذشته خراب نمی‌شود

#### 🗂️ مدیریت فعالیت‌ها
- انتخاب هر روز هفته و دیدن فعالیت‌های همان روز، **مرتب‌شده بر اساس ساعت**
- ویرایش و حذف (با پیام تأیید)

#### 📊 گزارش‌ها
- **هفتگی** و **ماهانه** (۳۰ روز اخیر): امتیاز کل، درصد موفقیت و وضعیت هر روز با تاریخ شمسی
- **سالانه**: خلاصه کل سال شمسی و کارت جداگانه برای هر ماه (امتیاز، درصد، تعداد روزهای سبز / زرد / قرمز)؛ سال کبیسه هم در نظر گرفته شده است
- **اهداف**: فهرست اهداف انجام‌شده همراه با تاریخ انجام

#### 🔔 یادآوری هوشمند
- نوتیفیکیشن **دقیقاً در ساعت فعالیت** و در روزهای تعیین‌شده
- تکرار خودکار **هر هفته**
- متن شخصی‌سازی‌شده با نام تو: «*{نام} عزیز، فعالیت «...» سر رسیده و باید انجامش بدی.*»
- با هر افزودن، ویرایش یا حذف فعالیت، آلارم‌ها دوباره تنظیم می‌شوند
- در صورتی که مجوز آلارم دقیق داده نشده باشد، به آلارم تقریبی برمی‌گردد

#### 👤 پروفایل
- ثبت نام کاربر برای نمایش در گزارش‌ها و متن یادآوری‌ها
- راه‌های ارتباط با توسعه‌دهنده

#### 🎨 رابط کاربری
- طراحی **Material** با پالت سرمه‌ای (`#003566`) و زرد (`#ffc300`)
- فونت **وزیرمتن (Vazirmatn)** در تمام صفحات
- صفحه اسپلش تمام‌صفحه
- سازگار با نوار وضعیت و نوار ناوبری اندروید

## 🇬🇧 English

### Introduction

**ZISTRO** is an Android app for planning and tracking your daily activities. It is built entirely in **Persian with full right-to-left support** and uses the **Jalali (Persian) calendar**. You define activities with a time and repeat days, check them off every day, and the app automatically gives each day a **score and a color-coded status**. Weekly, monthly and yearly reports show how you're progressing.

All data is stored **locally on your device**. No internet connection or account is required.

### ✨ Features

#### 📅 Today screen
- **Live Jalali date** with the weekday name
- Today's activities with a **one-tap completion check**
- Status and score card for the current day
- **Jalali calendar** with month navigation; past days are colored by their status
- **Yearly goals**: add, mark as done, or delete
- **Weekly plan**: number of activities per weekday at a glance (Saturday to Friday)
- **"Emergency day"** button for days when you can't follow the plan

#### 🎯 Scoring system

| Color | Status | Score |
|:---:|:---|:---:|
| 🟢 Green | All of the day's activities completed | 10 |
| 🟡 Yellow | Emergency day (set manually) | 5 |
| 🔴 Red | Past day with incomplete activities | 0 |
| ⚪ Gray | Current day, still in progress | — |

#### ➕ Add & edit activities
- Activity title with a **live preview of correctly shaped Persian text**
- Time input with **automatic 24-hour formatting** (e.g. `21:30`) and validation
- Weekly **repeat days** (one or many)
- An activity only counts from the day it was created, so older reports are never distorted

#### 🗂️ Activity management
- Pick any weekday and see its activities **sorted by time**
- Edit and delete (with a confirmation dialog)

#### 📊 Reports
- **Weekly** and **monthly** (last 30 days): total score, success percentage and per-day status with Jalali dates
- **Yearly**: full Jalali-year summary plus a card for each month (score, percentage, green / yellow / red day counts); leap years are handled
- **Goals**: list of completed goals with their completion dates

#### 🔔 Smart reminders
- Notification **at the exact activity time** on the chosen days
- Automatically **repeats every week**
- Personalized with your name
- Alarms are rescheduled whenever you add, edit or delete an activity
- Falls back to inexact alarms if the exact-alarm permission isn't granted

#### 👤 Profile
- Set your name, shown in reports and reminder messages
- Contact links for the developer

#### 🎨 UI
- **Material** design with a navy (`#003566`) and yellow (`#ffc300`) palette
- **Vazirmatn** font across all screens
- Full-screen splash screen
- Handles Android status bar and navigation bar insets

### 📲 Installation

1. Go to the **[Releases](https://github.com/AmirDehghanKar/ActivityTracker/releases/latest)** page.
2. Download **`Zistro-1_0_4.apk`**.
3. Open the file on your phone (allow installing from unknown sources for your browser or file manager if prompted).
4. On first launch, grant the **notification permission** so reminders can work.

**Minimum Android version:** 7.0 (API 24) · **Architecture:** `arm64-v8a`

### 🧰 Tech stack

| Area | Tool |
|:---|:---|
| Language | Python 3.11 |
| UI | Kivy 2.3.1 + KivyMD 1.2.0 |
| Database | SQLite |
| Jalali calendar | jdatetime |
| Persian text rendering | arabic-reshaper + python-bidi |
| Reminders | Java (`AlarmManager` + `BroadcastReceiver`) via Pyjnius |
| APK build | Buildozer + python-for-android |
| CI/CD | GitHub Actions |

```

├── main.py                  # Entry point, splash, screen manager

├── persian.py               # fa() helper for correct Persian rendering
├── reminders.py             # Notification scheduling from Python
├── screens/
│   ├── today_screen.py      # Today, calendar, goals, weekly plan
│   ├── add_edit_screen.py   # Add / edit activity
│   ├── manage_screen.py     # Activity management

│   └── profile_screen.py    # Profile and developer contact

    └── build.yml            # Automated APK build via GitHub Actions
```

### 🛠️ Run & build

**Run on desktop (for development):**

```bash
git clone https://github.com/AmirDehghanKar/ActivityTracker.git
cd ActivityTracker
pip install kivy==2.3.1 kivymd==1.2.0 arabic-reshaper python-bidi==0.4.2 jdatetime
python main.py
```

> Reminders are Android-only and are skipped on desktop.

**Build the APK:**

- **Automatic:** every `push` triggers the GitHub Actions workflow, and the APK is uploaded as an artifact.
- **Manual (Linux):**

```bash
pip install buildozer cython==0.29.34
buildozer android debug
```
